- API名：ヘルスチェックAPI

- パス：/api/health
- 対応コントローラー：HealthController
- 作成日：2026-06-15

---

## リクエスト仕様

リクエストパラメータなし

---

## レスポンス仕様

### 正常時（HTTP 200 OK）

| フィールド名 | 型 | 説明 |
|---|---|---|
| status | String | 常に"ok" |

### レスポンス例

```json
{
  "status": "ok"
}
```

---

## 処理フロー

### 1. HealthController.health()

- 処理なし
- `Map.of("status", "ok")` をHTTP200で返す

## エラーハンドリング一覧

本APIはDB接続や外部リソースへのアクセスを一切行わないため、アプリケーションが起動している限りエラーは発生しない。
