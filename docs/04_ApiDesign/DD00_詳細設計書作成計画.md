# DD00 詳細設計書作成計画

## 本ドキュメントの目的

- Excel-Like DB Editorの詳細設計書を作成するための計画を定義する
- 本ファイルを別スレッドのClaudeに渡すことで、途中から作業を引き継げるようにする
- 作成済み・未作成の状態を本ファイルで一元管理する

---

## プロジェクト概要（引き継ぎ用）

- アプリ名：Excel-Like DB Editor
- 構成：React（TypeScript）+ Spring Boot（Java 17）+ PostgreSQL
- アーキテクチャ：クリーンアーキテクチャ
- コンテナ：Docker（db-net外部ネットワーク使用）
- フロントポート：5173、バックポート：8080、DBポート：5432
- アプリ用スキーマ：db_editor（管理用5テーブル）
- 対象DB：ユーザが接続設定画面で登録した任意のPostgreSQL

## 詳細設計書フォーマット（引き継ぎ用）

各詳細設計書は以下の構成で作成する。

1. ヘッダー情報（機能名・API名・メソッド・パス・作成日）
2. リクエスト仕様（リクエストボディの項目定義・例）
3. レスポンス仕様（正常時・エラー時）
4. 処理フロー（Controller→UseCase→Gateway→Controllerの順で各ステップを記述）
5. エラーハンドリング一覧
6. 関連テーブルDDL（該当するもののみ）
