# 詳細設計作成計画

本ドキュメントは、基本設計書(001)の内容を元に、各機能の詳細設計を作成する際の順序・粒度・成果物を定義する。

## 詳細設計の作成方針

- 各機能ごとに1つの詳細設計ドキュメントを作成する
- フロントエンド・バックエンドの両面を1ドキュメント内に含める
- 画面モックアップは文字ベース（ASCII/Markdown）で表現する
- 実装計画(003)のフェーズと対応づけて作成順序を決定する

## 各詳細設計ドキュメントに含める項目

1. **概要** — 機能の目的と範囲
2. **画面レイアウト** — ASCII/Markdownによる画面構成
3. **画面項目定義** — 各項目の型・制約・初期値・イベント
4. **状態管理設計** — Zustandストアの構造
5. **API I/F定義** — リクエスト/レスポンスの型・ステータスコード
6. **バックエンド処理フロー** — ユースケース→リポジトリの処理手順
7. **エラーハンドリング** — 想定エラーと画面表示
8. **関連テーブルDDL** — CREATE文（該当するもののみ）
