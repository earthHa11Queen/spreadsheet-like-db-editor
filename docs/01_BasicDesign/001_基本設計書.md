# 基本設計書

## 1. システム概要

スプレッドシートライクなUIでPostgreSQLのテーブルを直接編集できる自分専用Webアプリケーション。
pgAdminの簡易版として、テーブル編集に必要な機能だけを搭載し、一画面完結・ショートカットキー重視の操作性を実現する。
共通APIとして構築することで、他の自前Webアプリからも呼び出し可能とする。

## 2. システム構成

```
[ブラウザ (Chrome)]
    │
    ├── :5173  フロントエンド (React + Vite)
    │
    └── :8080  バックエンド (Spring Boot)
                  │
                  └── :5432  PostgreSQL (既存コンテナ main-db)
```

- フロントエンド: TypeScript + React 18
- バックエンド: Java 17 + Spring Boot 3.2
- DB: PostgreSQL（既存コンテナ内にアプリ用DBを構築）
- コンテナ: Docker + docker-compose（既存Dockerネットワーク db-net に参加）
- アーキテクチャ: クリーンアーキテクチャ

### 4.2 コピーテーブル方式（編集の核心）

テーブル編集はDBの実テーブルを直接編集せず、以下の流れで行う：

1. テーブル選択時に実テーブルの全レコードを**コピー用一時テーブル**に複製
2. 画面上ではコピーテーブルを編集
3. Ctrl+Sで**編集履歴一時テーブル**に履歴保存（Undo/Redo用）
4. 「更新実行」ボタン押下で**バックアップ用一時テーブル**に現在の実テーブルを退避
5. 衝突検知API実行 → 衝突なければ実テーブルに反映
6. 衝突ありならDiff画面で手動解決

※一時テーブルはPostgreSQLのテンポラリテーブルで作成
